# Corresponding Source

The complete corresponding source for each published SC Mod Launcher binary is
available in the public repository:

<https://github.com/johnniewalker89/my-game-modding/tree/main/StarCitizen/SC_Mod_Launcher>

Official releases use tags named `sc-mod-launcher-vX.Y.Z`. To obtain the exact
source for a release, open its matching tag or the automatically generated
source archive on the GitHub Release page:

<https://github.com/johnniewalker89/my-game-modding/releases>

The WPF application and root launcher source are under `src/`. Build and test
entry points are under `tools/`, including `Build-WpfLauncher.ps1` and
`Build-ReleaseZip.ps1`.
